WristMemo プライバシーポリシー

WristMemo は、作者が自分のためだけに使う個人用のメモアプリです。作者以外の利用者はいません。

Google ユーザーデータの扱い

  • Google カレンダーには、作者が指示したメモを予定として追加するためだけにアクセスします（スコープ: calendar.events）。
  • 既存の予定を読み取ったり、第三者に渡したりはしません。
  • Google の認証情報はアプリのサーバー（Supabase）にだけ保存し、接続を解除すると削除します。

Google API から受け取った情報の使用は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。
